Identitas Siswa

0 dari 10 soal dijawab
1 Teka-Teki Profesi
"Aku bekerja di laut yang luas. Aku melempar jala untuk mencari ikan. Aku seorang perempuan."

Siapakah aku?
Pembahasan: Kata kunci "laut/ikan" = Nelayan (صَيَّاد), dan karena "perempuan" maka ditambah huruf ة (ta marbutah) menjadi صَيَّادَة.
2 Pola Logika (Analogi)
Perhatikan pola berikut:
مُهَنْدِس (Insinyur Laki-laki) → مُهَنْدِسَة (Insinyur Perempuan)

Maka: مُمَرِّض (Perawat Laki-laki) → ...?
Pembahasan: Pola yang sama: menambah huruf ة di akhir kata untuk mengubah profesi laki-laki menjadi perempuan. Jadi مُمَرِّض menjadi مُمَرِّضَة.
3 Petunjuk Konteks
"Paman Ahmad memakai helm kuning. Ia sedang memeriksa gambar desain gedung bertingkat di kantornya."

Profesi Paman Ahmad dalam bahasa Arab adalah...
Pembahasan: Kata kunci "helm" dan "desain gedung" menunjukkan profesi Insinyur (المُهَنْدِسُ).
4 Analisis Kalimat
Perhatikan kalimat berikut:
أُمِّي تَعْمَلُ فِي المَسْتَشْفَى. هِيَ تَعْتَنِي بِالمَرْضَى.
(Ibuku bekerja di rumah sakit. Ia merawat orang-orang sakit.)

Kata yang tepat untuk melengkapi profesi ibu adalah...
Pembahasan: Kata kunci "Ibu" (perempuan) + "merawat orang sakit di rumah sakit" = Perawat perempuan (مُمَرِّضَة).
5 Detektif Tata Bahasa
Kata خَيَّاطَة memiliki huruf khusus di akhir kata yang membedakannya dengan خَيَّاط.

Huruf apakah itu dan apa fungsinya?
Pembahasan: Huruf ة (ta marbutah) di akhir kata bahasa Arab berfungsi untuk menunjukkan jenis kelamin perempuan (muannats).
6 Penalaran Terbalik
Manakah pernyataan di bawah ini yang TIDAK MASUK AKAL (tidak logis)?
Pembahasan: Perawat seharusnya bekerja di rumah sakit (المُسْتَشْفَى), bukan di sekolah (المَدْرَسَة).
7 Teka-Teki Singkat
"Aku punya jarum dan benang, tapi aku bukan dokter yang menyuntik pasien. Aku seorang laki-laki."

Siapakah aku?
Pembahasan: Teka-teki "jarum & benang" + "laki-laki" = Penjahit laki-laki (خَيَّاط).
8 Penerjemahan Logis
"Kakekku adalah seorang nelayan, dan nenekku adalah seorang penjahit."

Terjemahan bahasa Arab yang paling tepat adalah...
Pembahasan: Kakek = صَيَّادٌ (laki-laki), Nenek = خَيَّاطَةٌ (perempuan).
9 Deduksi Ganda
Andi ingin menjadi dokter laki-laki, sedangkan Sinta ingin menjadi perawat perempuan.

Kata bahasa Arab yang tepat secara berurutan adalah...
Pembahasan: Andi (laki-laki) = طَبِيب, Sinta (perempuan) = مُمَرِّضَة.
10 Hubungan Kata
Kata المُسْتَشْفَى (Rumah Sakit) → tempat kerja profesi...
Kata البَحْر (Laut) → tempat kerja profesi...

Pilihan yang tepat untuk mengisi titik-titik di atas adalah...
Pembahasan: Tempat kerja: Rumah Sakit → Perawat (المُمَرِّضُ), Laut → Nelayan (الصَّيَّادُ).

Panduan Integration Google Drive

Ikuti langkah berikut agar hasil pengerjaan siswa terbuatkan Folder Otomatis & File Rekap Google Sheets di Google Drive Anda:

  1. Buka script.google.com lalu buat Proyek Baru.
  2. Salin (copy) seluruh kode Google Apps Script (`Code.gs`) di bawah ini:
function doPost(e) { try { var data = JSON.parse(e.postData.contents); // 1. Nama Folder yang akan dibuat otomatis di Google Drive Guru per Kelas var folderName = "Rekap Nilai Bahasa Arab - " + (data.kelas || "Kelas 6"); // 2. Cari atau Buat Folder Otomatis di Google Drive var folders = DriveApp.getFoldersByName(folderName); var folder; if (folders.hasNext()) { folder = folders.next(); } else { folder = DriveApp.createFolder(folderName); } // 3. Cari atau Buat Spreadsheet Rekap di dalam Folder tersebut var fileName = "Nilai_Bahasa_Arab_" + (data.kelas || "Kelas_6").replace(/\s+/g, '_'); var files = folder.getFilesByName(fileName); var ss; if (files.hasNext()) { ss = SpreadsheetApp.open(files.next()); } else { // Buat file Google Sheet baru ss = SpreadsheetApp.create(fileName); var file = DriveApp.getFileById(ss.getId()); // Pindahkan file ke dalam folder khusus folder.addFile(file); DriveApp.getRootFolder().removeFile(file); // Buat Header Kolom var sheet = ss.getActiveSheet(); sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Kelas", "No. Absen", "Nilai Akhir", "Benar", "Salah", "Tidak Dijawab"]); sheet.getRange(1, 1, 1, 8).setFontWeight("bold").setBackground("#1e40af").setFontColor("#ffffff"); } // 4. Masukkan Data Nilai Siswa var sheet = ss.getActiveSheet(); sheet.appendRow([ new Date().toLocaleString("id-ID"), data.nama, data.kelas, data.absen, data.nilai, data.benar, data.salah, data.kosong ]); return ContentService.createTextOutput(JSON.stringify({ status: "success", message: "Data tersimpan" })) .setMimeType(ContentService.MimeType.JSON); } catch (err) { return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() })) .setMimeType(ContentService.MimeType.JSON); } }
  1. Klik Deploy (Terapkan) → Deployment Baru (New Deployment).
  2. Pilih Jenis: Web App (Aplikasi Web).
  3. Atur "Who has access" / "Siapa yang memiliki akses" menjadi Anyone (Siapa saja).
  4. Salin Web App URL yang dihasilkan, lalu tempel pada variabel GOOGLE_SCRIPT_URL di file ini (sekitar baris 380).
